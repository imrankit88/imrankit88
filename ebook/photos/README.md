# Real photos for the book

Put a photo in this folder, named after the page it belongs to (for example `salih1.jpg`).
Then run `node ebook/build.js` and the photo replaces the drawing on that page. Pages without a photo keep their drawing.

- **Size:** at least 2000 px wide, landscape. The arch frame crops the edges a little.
- **Formats:** .jpg, .png or .webp
- **No people's faces:** keep the rule that no prophet or person appears.
- **Licence:** use only photos you took yourself, bought, or that are free for commercial use, such as Pexels, Unsplash, or Wikimedia Commons photos marked CC0 or "public domain". Don't use AI images or photos copied from Google.
- **Credits:** if a licence asks for credit, add it to `credits.json` like this: `{"salih1": "Photo by Name / Pexels"}`. Credits print on the copyright page.
